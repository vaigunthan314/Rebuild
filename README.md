CAMPUSCODE CINEMATIC SCROLL EXPERIENCE
=======================================

Overview
--------
A scroll-driven, 3D interactive web platform for CampusCode.
Built with Vite vanilla JavaScript, Three.js, and GSAP ScrollTrigger.

Theme and Aesthetics
--------------------
- Pure brand palette: Black, Violet, and Lime Green.
- Light, airy, frosted-glass interface surfaces.
- Smooth full-page JPG canvas sequence with dual-frame alpha blending.
- 3D emblem landing sequence with bounce physics and camera shake.

Key Pages
---------
- index.html: Landing page with hero, ticker, experience, about, how-it-works, mission, community, and footer.
- login.html: Student login portal with frosted card and brand emblem.
- register.html: Registration screen with tiered options and validation.
- dashboard.html: Student command center with live telemetry and track progress.

Development Commands
--------------------
- npm install : Install dependencies
- npm run dev : Start local development server
- npm run build : Build optimized production bundle
- npm run preview : Preview production build locally
